# Calculator

## Purpose
Basic example of different features of unit testing in PHPUnit.
The system under test is a basic calculator module that implements the functions `sum`, `subtract`, `multiply` and `divide`.

## Usage
`vendor\bin\phpunit --colors test` (adjust path traversal depending on OS and CLI)

## Tools
PHPUnit 11.5 / PHP8
